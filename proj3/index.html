1.3 One-step denoising

def one_step_denoise(x, t, condition, predict_velocity):
    velocity = predict_velocity(x, t, condition)
    return x + (1-t)*velocity

The estimate degrades as t falls: at 0.75 it is close to the original, at 0.25 the model invents plausible structure that is not there.

1.4 Visualizing velocity

The predicted update is a smooth, low-frequency version of the ground-truth update, which still carries the sampled noise. Error concentrates on edges and on the fur texture, and falls as t rises and less of the update is left to predict.

1.5 Iterative denoising with Euler sampling

@torch.inference_mode()
def euler_sample(x_start, t_start, step_size, velocity):
    curr_t = t_start
    curr_x = x_start

    states = [(curr_t, x_start)]
    num_updates = 0
    while curr_t<1:
      step = min(1-curr_t, step_size)
      curr_vel = velocity(curr_x, curr_t)
      curr_x = curr_x + step * curr_vel
      curr_t += step
      num_updates += 1
      if num_updates % 5 == 0 or curr_t == 1:
        states.append((curr_t, curr_x))
    return curr_x, states

One-step scores the lowest MSE but is visibly soft, because averaging over everything the image could have been is exactly what MSE rewards. Euler is slightly worse by that measure and clearly better by eye: it recovers whisker and fur detail that one-step smooths away.

1.6 Generating images from noise

All five come out as portraits of people, so the generic prompt is not neutral. Quality is uneven: anatomy is distorted in two of the five and faces are blurred in another.

2.1 Classifier-free guidance

def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
    conditional_velocity = predict_velocity(x, t, condition)
    return conditional_velocity + w * (conditional_velocity - predict_velocity(x, t, null_condition))

Every sample is now a clean, sharply lit studio portrait, and the distortions are gone. The cost is diversity: all five converge on the same head-and-shoulders framing against a dark background, where the unguided set at least varied in pose and crop.

3.1 Image-to-image editing

def edit(image, noise, t_start, condition, predict_velocity, w=7, step_size=0.02):
    ct = t_start
    cx = t_start*image + (1-t_start)*noise

    while ct < 1:
      step = min(1-ct, step_size)
      velocity = cfg_velocity(cx, ct, condition, w, predict_velocity)
      cx = cx + step * velocity
      ct += step
    return cx

At t = 0.02 almost nothing of the input survives and the model returns a generic photo. By t = 0.25 the layout is back and only texture and lighting have been reworked.

Editing hand-drawn and web images

The drawings need a smaller starting time than the photographs to become plausible, since a flat sketch is further from the model's distribution than a photo is.

3.2 Text-guided editing

3.3 Visual anagrams

def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    ct = 0
    cx = noise

    while ct < 1:
      step = min(1-ct, step_size)
      velocity_a = cfg_velocity(cx, ct, condition_a, w, predict_velocity)
      velocity_b = rotate180(cfg_velocity(rotate180(cx), ct, condition_b, w, predict_velocity))
      cx = cx + step * (velocity_a + velocity_b) / 2
      ct += step
    return cx

3.4 Hybrid images

def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
  ct = 0
  cx = noise

  while ct < 1:
    step = min(1-ct, step_size)
    velocity_a = cfg_velocity(cx, ct, condition_a, w, predict_velocity)
    velocity_b = cfg_velocity(cx, ct, condition_b, w, predict_velocity)

    cx = cx + step * (lowpass(velocity_a) + (velocity_b - lowpass(velocity_b)))
    ct += step
  return cx

1.2.2 Out-of-distribution noise levels

The model holds up to about σ = 0.6 and fails past it. Trained on one noise level, it has learned how much signal to expect, so at σ = 1.0 it over-corrects and produces a confident but wrong digit.

1.2.3 Denoising pure noise

Every output is the same faint grey blob, and the loss plateaus almost immediately. The input carries no information about which digit to produce, so under MSE the best possible prediction is the one minimising squared distance to every training image at once, which is their mean. The blob is the average MNIST digit: bright in the centre where strokes usually fall, dark at the edges where they rarely do.

Removing the learning rate scheduler

class_fm = train_class_fm(1e-2, True, 'class_fm')
# constant lr equal to the scheduler's final lr, to avoid instability from staying at 1e-2
class_fm_nosched = train_class_fm(1e-3, False, 'class_fm_nosched')

The exponential schedule decays from 1e-2 by 0.11/10 each epoch, ending at 1e-3. Holding the rate at 1e-2 without it is unstable, so I trained at a constant 1e-3, the value the schedule finishes on. Final sample quality matches, and the loss curve is flatter from the start rather than dropping sharply and then settling.
